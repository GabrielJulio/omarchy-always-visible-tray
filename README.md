# Always Visible Tray for Omarchy

A customized Omarchy system tray that:

- Shows all tray icons by default
- Automatically shows newly created tray icons
- Removes the drawer arrow when there are no hidden/drawer items
- Keeps explicitly hidden icons hidden

## Install

    omarchy plugin add https://github.com/gabrieljuliobs/omarchy-always-visible-tray.git --enable

## Based on

The built-in `omarchy.tray` plugin.
